The new [Template.ExecuteWithMethods] method executes a template with a
[FuncMap] whose functions take the receiver as their first argument and
stand in for the methods the template names. A name not in the map resolves
to a struct field or map key, never to a method of the data by reflection,
so a program whose template executions all use ExecuteWithMethods lets the
linker drop the methods that nothing else references.
