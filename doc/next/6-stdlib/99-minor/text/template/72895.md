The new `templatenomethods` build tag disables method lookup in template
field evaluation, so a name such as `.Method` no longer resolves to a
method of the data. Because the lookup used [reflect.Value.MethodByName],
every program that executes a template otherwise keeps every exported
method reachable, which can add tens of megabytes to a binary. A template
that names a method fails with an execution error when the tag is set.
